# Tugas Rutin 2 Pemrograman Web Landing Page

Repository ini berisi Tugas Rutin Pertemuan 2 mata kuliah Pemrograman Web.

## Deskripsi

Tugas ini merupakan pengembangan landing page dengan menggunakan HTML dan CSS. CSS digunakan untuk mengatur tampilan, warna, layout, serta membuat halaman menjadi lebih menarik dan terstruktur.

## Teknologi

- HTML5
- CSS3

## File Utama

- `index.html` — struktur halaman web
- `style.css` — styling halaman
- `images/` — aset gambar yang digunakan

## Mata Kuliah

Pemrograman Web
